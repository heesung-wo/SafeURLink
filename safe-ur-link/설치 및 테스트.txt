설치 및 사용 방법

1. 본 저장소를 ZIP으로 다운로드하거나 복제한 뒤 압축을 해제합니다.
2. Chrome에서 `chrome://extensions`, Whale에서 `whale://extensions`를 엽니다.
3. **개발자 모드**를 활성화하고 **압축 해제된 확장 프로그램 로드**를 선택합니다.
4. `manifest.json`이 들어 있는 **`safe-ur-link/` 폴더**를 지정합니다. 저장소 최상위 폴더를 선택하지 않도록 주의합니다.
5. 도구 모음의 SafeURLink 팝업에서 URL을 입력해 검사하거나 **현재 탭 검사**를 실행합니다. 설정 화면에서 허용·차단 목록과 위협 정보 갱신 상태를 확인할 수 있습니다.

* NOTE *
실제 시그니처는 GitHub Pages에 게시된 공개 피드에서 내려받아 IndexedDB에 저장합니다. 
저장소에 들어 있는 `safe-ur-link/public/signatures.json`은 **시연용 2건의 데이터**이며 실제 전체 시그니처 DB가 아닙니다. 따라서 초기 갱신에는 네트워크 연결이 필요할 수 있습니다.


테스트 및 추가 정량 검증

Node.js 20 이상을 준비하고 저장소 최상위 폴더에서 다음 명령을 실행합니다.

```powershell
cd safe-ur-link
npm.cmd test
npm.cmd run eval:synthetic
npm.cmd run stress:dnr
```

- `npm test`: URL 정규화·시그니처 관리·DNR·자동 갱신 등 **124건의 기능 테스트**를 실행합니다.
- `npm run eval:synthetic`: 가상 `.test` URL 10,000건을 이용한 기대 판정 비교 시험입니다.
- `npm run stress:dnr`: 합성 시그니처 100,000건으로 DNR 차단 규칙 **29,700개 생성**을 확인합니다.

위 합성 시험 결과는 실제 악성 URL의 탐지율이나 실제 브라우저 차단 성공률이 아닙니다.

### 브라우저 기반 추가 검증

추가 검증 도구와 결과 자료는 `safe-ur-link/tests/추가_정량검증/`에 포함되어 있습니다. 확장 프로그램을 개발자 모드로 설치한 뒤 확장 프로그램 ID를 확인하고 아래 주소에서 실행합니다.

```text
chrome-extension://<확장프로그램ID>/tests/추가_정량검증/evaluation.html
```

Whale에서는 `whale-extension://` 형식도 시도할 수 있습니다. 자세한 절차는 해당 폴더의 `README.txt`를 참고하세요.
