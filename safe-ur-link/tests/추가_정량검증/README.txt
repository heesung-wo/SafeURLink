SafeURLink 추가 정량 검증

목적: 현재 DB의 등록 시그니처 인식, 정상 URL 후보 오경고, 브라우저 DNR 규칙 일치 여부를 확인합니다. 실제 악성 사이트에 접속하지 않습니다.

1. 실행 방법
- `safe-ur-link/` 폴더를 Chrome/Whale에 '압축 해제된 확장 프로그램 로드'로 설치합니다.
- 확장 프로그램의 시그니처 갱신 및 DNR 규칙 준비 상태를 확인합니다.
- 확장 프로그램 ID를 확인한 뒤 아래 주소를 엽니다.
  chrome-extension://<확장프로그램ID>/tests/추가_정량검증/evaluation.html
  (Whale에서 필요한 경우 whale-extension:// 형식도 시도할 수 있습니다.)

2. 검사 순서
① '상태 확인': DB 건수, DNR 규칙 수, 피드 시각 확인
② '등록된 활성 시그니처 인식률': 4개 출처에서 각각 최대 50건, 총 최대 200건 검사
③ '정상 URL 후보 오경고 검사': 같은 폴더의 SafeURLink_normal_candidates_500.csv 선택, 500건 검사
④ 'DNR block 규칙 일치율': 설치된 규칙 중 최대 50건을 가상 요청으로 검사
⑤ 각 결과 CSV 및 '요약 JSON 다운로드' 저장

3. 보관된 시험 결과 (2026-11-14)
- 등록 시그니처 200건: Malicious 200건, 오류 0건 (인식률 100%)
- 정상 URL 후보 500건: 경고 0건, 오류 0건 (표본 오경고율 0%)
- DNR 가상 요청 50건: 50건 일치, 오류 0건 (일치율 100%)
- 상세 요약: SafeURLink_evaluation_summary.json

주의 사항
- 등록 시그니처 인식률은 **이미 DB에 있는 URL**의 조회·판정 결과이며, 미등록 악성 URL 탐지율이 아닙니다.
- 정상 URL은 데이터셋의 '정상 후보'이며, 결과를 전체 사이트의 오탐률로 일반화할 수 없습니다.
- DNR 결과는 testMatchOutcome() 가상 요청 결과이며 실제 악성 사이트 접속 차단율이 아닙니다.
- 피드·사용자 설정 상태에 따라 재실행 결과가 달라질 수 있습니다. URL별 결과 CSV에는 악성 URL이 포함될 수 있으므로 공개 저장소에 올리지 마세요.
